## Tech Stack

- **Backend**: Python
- **Frontend**: TypeScript, React

## Getting Started

### Backend (Python)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Frontend (TypeScript / React)

```bash
npm install
npm run dev
```
